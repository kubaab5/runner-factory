# Runner Factory — фабрика гейт-раннеров

Один движок (Phaser 3, псевдо-3D дорога) → много игр. Новая игра = файл в `src/games/<id>.ts` (тема, персонаж по уровням силы, предметы, босс, мемные фразы) + строка в `src/games/index.ts`.

Механика: бежишь, проходишь ворота «+N / −N / ×2 / ÷2», собираешь бонусы, уворачиваешься от помех. Число меняет персонажа (6 стадий). В конце бой с боссом: если ты сильнее — босс улетает на лестницу множителей ×1…×10.

## Игры
| id | Название | Число | Босс |
|---|---|---|---|
| `aura` | Аура Ран / Aura Run | аура | Главный NPC |
| `gym` | Качалка Раш / Gym Rush | сила | Тренер Бульдозер |

## Команды
```
npm i
npm run dev            # http://localhost:5173/?game=gym&mockads
npm test               # генератор уровней (босс проходим / непроходим при плохой игре), рекламная политика
npm run build          # все игры → dist/<id>/ и dist/<id>.zip (zip грузится на порталы)
npm run build -- gym   # одна игра
npm run e2e            # Playwright: меню → забег → босс → награда → скины, скриншоты в e2e/out
```

## Реклама и платформы
Playgama Bridge (`src/ads/BridgeAds.ts`) — один SDK для Playgama, CrazyGames, Yandex, Poki, GameDistribution и др. Без Bridge (локально, `?mockads`) — тестовые заглушки.
- Rewarded: ×3 монеты, реванш с боссом, старт ×2, бесплатный скин, бесплатная прокачка (раз в 10 мин), 20 минут без рекламы за 2 ролика.
- Interstitial: после 2-го уровня, не раньше 60 с сессии, кулдаун 60–90 с, перед показом заставка «перерыв».
- Банер снизу после 2-го уровня.
- Шлёт платформе `game_ready`, `gameplay_started/stopped`, слушает паузу и звук.

## Как добавить игру
1. Скопировать `src/games/gym.ts` → `src/games/<id>.ts`, поменять тексты, цвета, SVG.
2. Добавить в `GAMES` в `src/games/index.ts`.
3. `npm test && npm run build -- <id>` → загрузить `dist/<id>.zip`.
